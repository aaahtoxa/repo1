# \# QA Pet‑Project: API Testing \& Documentation

# 

# Пет‑проект для демонстрации навыков тестирования и документирования REST API.

# 

# \## Что внутри

# 

# \- `collections/` — Postman‑коллекция с тестами (CRUD, негативные сценарии, валидация JSON).

# \- `specs/` — OpenAPI‑спецификация (версия 3.0.3), сгенерированная из коллекции.

# 

# \## Как использовать

# 

# \- Импортируй коллекцию в Postman и запускай тесты через Newman/CI.

# \- Открой `openapi.yaml` в Swagger Editor или загрузи в SwaggerHub для просмотра документации.

# 

# \## Стек

# 

# \- Postman

# \- OpenAPI 3.0.3

# \- Git
